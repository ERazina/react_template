React Boilerplate Template
Бойлерплейт для быстрого старта разработки на стеке react/typescript/styled-components.

Github Репозиторий

Стек:
React
TS
react-router
StyledComponents

Быстрый старт
git clone git@github.com:ERazina/react_template.git
pnpm install
pnpm run start

Скрипты

dev - Запуск dev окружения

build - Сборка

lint - Проверка кода линтером

lint:fix - Автофикс через линтер

typecheck - Проверка типов

typecheck:fix - Автофикс через tsc

preview - Предпросмотр собранного проекта
